# 超星学习通自动化 Web 控制台设计规范

## 背景与目的

当前超星学习通任务处理程序主要依赖命令行交互与手动编辑配置文件。在多账号切换、多课程挑选和批量设置课程列表时，命令行输入不够直观，且多线程并发刷课时控制台字符滚动难以清晰掌握各任务点的实时视频进度。同时，当题库回退至手动输入模式时，命令行阻塞等待输入会阻碍多任务并发，且缺乏图形化作答体验。此外，各类题库凭证、接口密钥、并发数和重做开关等核心配置项均依赖手动修改配置文件，容易出现格式错误。

本项目为该程序构建全功能的本地 Web 控制台界面：程序启动后拉起本地 Web 服务并自动打开浏览器，提供直观的多账号登录与切换、课程列表勾选保存、独立双分栏滚动、全局与单视频实时倍速调节、任务总进度与并发线程监控、章节测验手动答题弹窗适配，以及全量参数的可视化表单设置。

## 目标与非目标

### 核心目标

- 本地轻量化架构：利用项目已有依赖 Flask 提供本地服务，零附加编译链，用户无需安装 Node.js 或前端构建工具。
- 前端源码目录分层：前端代码杜绝单文件混杂，在独立文件夹中解耦为 HTML 结构模板、CSS 样式表与 JavaScript 业务脚本。
- 多账号存储与配置文件独立：默认将账号配置保存在运行目录下的 accounts 目录中，每个账号对应一个独立的配置文件，会话凭证保存在对应配置文件的 cookies 字段中。
- 账号登录弹窗支持：前端提供添加与登录账号弹窗，同时支持超星 APP 扫码登录与账号密码登录，登录成功自动落盘至 accounts 目录并切换至该账号。
- 课程挑选与配置持久化：以结构化表格展示课程名称、编号、班级、教师与当前完成度；支持搜索、全选与仅选未完成；勾选后一键写入当前账号配置文件的课程列表项。
- 视口独立双分栏滚动：页面高度填满视口，左侧选课区与右侧监控面板拥有独立滚动条，互不干扰联动。
- 实时倍速控制：全局倍速滑动条在鼠标松开时下发配置；每个播放中的视频卡片拥有独立的微型倍速调节弹窗，弹窗具备自适应朝向能力，防止被容器裁剪。
- 实时监控大屏：同屏展示全局完成百分比、任务点统计、各工作线程实时章节名、视频时间轴与进度条、测验答题状态以及带时间戳的控制台日志。
- 手动答题模式 Web 适配：当遇到需要手动输入的测验题目时，后端通过状态总线捕获答题请求，通过 SSE 事件流向前端广播题目弹窗；前端呈现单选、多选、判断、填空或批量输入表单，用户点击提交后异步恢复工作线程执行；同时支持手动跳过与超时回退。
- 全量可视化配置中心：提供完整的设置面板，覆盖基础运行设置、题库提供方及其鉴权参数、手动模式参数与推送通知渠道，支持直接读取并保存至当前账号配置文件。
- 堆叠通知动效：右下角操作反馈采用自右向左平移入队、已有提示依次向上平移动画、最新提示保持在最底部的通知队列。

### 非目标

- 不搭建云端多租户或公网托管鉴权服务，仅作为本地单机控制台绑定于本机回环地址。
- 不废弃现有的命令行入口，保持原有命令行参数完全向后兼容。

### 反目标

- 严禁引入破坏开箱即用体验的重型前端打包工程。
- 严禁在代码与界面中使用装饰性 Emoji，严格采用标准 SVG 矢量图形。

## 架构与技术选型

### 后端架构

- Web 框架：利用已有 Flask 库构建轻量 API 与页面路由。
- 账号与凭据管理：管理 accounts 目录下的账号 INI 配置文件，提供扫码会话池与密码验证服务。
- 配置中心服务：负责全量 INI 配置的结构化读写、默认模板对照与合法性校验。
- 任务执行器与状态总线：将现有任务执行逻辑包装为后台工作线程，通过单例状态总线分发倍速控制、收集各线程运行状态并调度手动答题队列。
- 数据交互协议：提供标准的 RESTful JSON 接口与长连接 Server-Sent Events 事件流。

### 前端目录分层结构

前端源码完全剥离独立存放，目录层级划分如下：

```
web/
├── templates/
│   └── index.html
└── static/
    ├── css/
    │   └── style.css
    └── js/
        ├── api.js
        └── app.js
```

- HTML 模板：承载语义化骨架、多账号切换栏、选课面板、监控面板、登录弹窗、手动答题弹窗与全量设置弹窗。
- CSS 样式表：集中定义暗色主题变量、双分栏独立滚动通道、平滑弹性过渡、自适应弹窗样式、设置面板分类布局与模态对话框样式。
- JS 脚本分层：拆分为数据请求层与视图交互层，负责事件绑定、选课逻辑、扫码轮询、多账号状态同步、倍速设置、手动答题交互、全量配置提交与通知队列渲染。

### 视觉与排版系统

- 视觉风格：基于深色工程运维调性，主色调采用深灰背景搭配科技蓝与翡翠绿。
- 字体系统：采用系统无衬线字体，所有数字、进度读数、编号、日志与时间采用等宽字体并启用表格对齐特性。
- 布局结构：固定顶部导航栏，主体采用双列等高自适应容器，左右子面板各自设置独立纵向滚动通道。

## 详细功能模块设计

### 账号存储与管理模块

- 目录结构：在工作根目录建立 accounts 目录，遍历该目录下所有的 ini 文件作为已知账号。
- 文件内容：各账号文件包含 common、tiku、notification 节，包含账号密码、cookies、课程列表及自定义个性化配置。
- 切换流程：下拉菜单遍历已存账号文件；用户切换后，后端读取目标配置文件的 cookies 字段并装载到会话中，即时刷新该账号课程列表与配置信息。

### 扫码登录与密码登录认证模块

- 扫码登录流程：
  - 后端请求超星登录页拉取动态凭证，生成二维码图片并返回 Base64 数据。
  - 前端以一秒半间隔轮询后端状态接口。
  - 手机端扫码并确认后，接口解析登录结果并提取完整会话 Cookies。
  - 自动在 accounts 目录下创建以账号编号命名的配置文件并存入 Cookies 字段。
- 账号密码登录流程：
  - 前端表单收集手机号与密码。
  - 后端发起认证，获取会话并保存至对应的账号配置文件中。

### 课程挑选与配置保存模块

- 课程列表获取：调用课程获取接口读取当前活动账号的课程数组。
- 过滤机制：前端输入框实时进行标题、编号、班级或教师名过滤。
- 配置生成：提取所有被勾选课程编号，以英文逗号拼接后写入当前账号配置文件的 course_list 字段。
- 状态提示：左下角常驻显示当前已选中课程门数。

### 运行控制与倍速调节模块

- 全局倍速控制：设置范围 1.0x 至 2.0x，步长 0.1；滑动条仅在触发松开事件后广播更新；提供预设档位按钮一键选择。
- 线程独立倍速：每个运行中的视频线程卡片均配有倍速调节按钮，点击触发自适应弹窗；弹窗检测与视口顶部距离，上方空间不足时自动向下弹出，点击档位即时修改该线程专属播放速率。

### 实时监控面板与日志队列

- 指标卡片：总任务点完成百分比、运行总耗时、测验通过次数。
- 线程动态卡片：对应指定并发线程数展示当前处理的章节小节名、课程名、已播放秒数与总秒数、动态进度条及状态标签。
- 日志控制台：记录关键操作与处理结果，支持内容自动滚动置底。

### 手动答题模式 Web 交互模块

- 触发流程：
  - 章节检测遇到未命中自动题库或配置为 TikuManual 时，题库模块检查是否处于 Web 模式。
  - 若处于 Web 模式，向 TaskStateHub 注册作答会话并派发会话标识，工作线程进入安全条件阻塞状态。
  - TaskStateHub 通过 SSE 广播 MANUAL_QUESTION_REQUEST 事件，载荷包括题目类型、题干、格式化选项列表及超时时间。
- 前端作答体验：
  - 前端检测到作答事件后弹出浮层作答窗口或悬浮告警通知条。
  - 界面针对单选题显示单选圆钮，多选题显示多选方框，判断题显示正确与错误快速操作卡片，填空题显示输入框，同时保留批量文本输入模式切换。
  - 用户选定答案后点击提交作答，前端发起对应提交接口请求。
  - 用户可点击跳过此题，后台将以空答案继续执行。
- 线程唤醒：
  - 后端接收到答案后，将答案规范化并解除对应工作线程的等待锁，流程恢复继续执行。

### 全量可视化配置管理模块

- 界面架构：前端设置模态窗分门别类展示四类配置卡片：
  - 基础运行设置：并发章节数 jobs、未开启章节动作 notopen_action、重试间隔 retry_interval、测验自动重做开关 work_redo_enabled 与最大重做次数 work_max_retries、增加学习次数开关与目标值。
  - 题库通用设置：题库提供商顺序组合多选与输入 provider、是否提交答题 submit、最低覆盖率要求 cover_rate、搜索时间间隔 delay、大模型连通性检测开关 check_llm_connection。
  - 扩展题库参数：言溪题库凭证、LIKE 知识库凭证与视觉搜索开关、TikuAdapter 接口地址、GO 题库鉴权与退避参数、自定义大模型接口地址与模型名称及密钥与代理、硅基流动专用端点与模型及密钥。
  - 手动答题与通知配置：手动模式默认输入方式、批量输入分隔符、判断题映射列表；通知服务提供方选择及各服务的推送地址或用户标识。
- 持久化交互：
  - 点击保存时，前端统一将表单对象发送至全量配置保存接口。
  - 后端解析并写入当前活动账号的配置文件，关键字段同步通知 TaskStateHub 即时生效。

### 交互反馈与通知系统

- 浮层容器固定于视口右下角，采用垂直弹性布局。
- 新通知自右向左平移划入并挂载在最底部；已有通知在高度变化时平滑上移；显示超时后反向向右滑出并从文档移除。

## REST API 与 SSE 事件接口规范

### RESTful 接口

- `GET /api/accounts`：列出 accounts 目录下所有配置文件及当前活动账号。
- `POST /api/accounts/switch`：切换当前活动账号，入参包含 account_id 字段。
- `POST /api/auth/qr/create`：创建超星扫码登录会话，返回 Base64 二维码与会话标识。
- `GET /api/auth/qr/status/<session_id>`：检查扫码登录状态。
- `POST /api/auth/login`：账号密码直接认证，入参包含 username 与 password 字段。
- `GET /api/courses`：获取当前活动账号的全部课程列表及章节统计。
- `POST /api/config/course_list`：保存勾选课程列表，入参包含 course_list 数组。
- `GET /api/config/full`：获取当前活动账号的完整结构化配置，缺省字段自动由模板补齐。
- `POST /api/config/full`：更新当前活动账号的完整配置，入参为结构化配置对象。
- `POST /api/speed/global`：修改全局播放倍速，入参包含 speed 浮点数值。
- `POST /api/speed/worker`：修改指定工作线程的播放倍速，入参包含 worker_id 与 speed 字段。
- `POST /api/task/start` 与 `POST /api/task/stop`：控制后台自动化刷课任务启动与停止。
- `GET /api/manual/pending`：获取当前待作答的手动题目列表。
- `POST /api/manual/answer`：提交手动题目的用户答案，入参包含 prompt_id 与 answer 字段。
- `POST /api/manual/skip`：跳过当前手动题目，入参包含 prompt_id 字段。

### SSE 实时事件流

- `STATUS_UPDATE`：推送当前总体进度、活动工作线程快照、各视频进度百分比与秒数。
- `LOG_APPEND`：推送新产生的带时间戳控制台日志条目。
- `SPEED_CHANGE`：广播全局或线程倍速变更事件。
- `MANUAL_QUESTION_REQUEST`：广播新的手动答题需求，载荷包含 prompt_id、课程信息、章节名、题型、题目文本及选项。
- `MANUAL_QUESTION_RESOLVED`：广播某手动题目已作答或已跳过，通知前端关闭对应作答窗口。
