# Web 控制台与可视化设置实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 为超星学习通构建本地 Web 控制台界面，支持扫码与密码登录、多账号独立配置隔离、双栏独立滚动、实时倍速控制、章节测验手动答题弹窗适配与全量参数可视化配置中心。

**Architecture:** 后端利用内置 Flask 搭建 REST 与 SSE 路由，通过账号管理器维护 accounts 目录下的独立配置，通过状态总线分发倍速与调度手动答题队列；前端解耦为 HTML 结构、CSS 样式与 JS 交互三层静态资源并托管在 web 目录。

**Tech Stack:** Python 3.13, Flask 3.1, Standard Library unittest, Vanilla HTML5, CSS3, ES6 JavaScript.

**Spec:** docs/superpowers/specs/2026-10-28-web-gui-design.md

## 全局约束规范

- 严禁引入 Node.js 或 npm 打包编译工具链，前端采用原生规范分层组织。
- 严禁在界面或源码中使用装饰性 Emoji 表情字符，全量使用标准矢量 SVG 图标。
- 账号文件保存在工作目录下的 accounts 目录，以独立的 ini 文件存储，会话凭证写入对应文件的 cookies 字段。
- 所有表格数值、标识符、进度百分比与时间采用等宽字体与表格数字对齐。
- Git 提交信息严格保持小写动词开头、无句号、长度不超过五十字符。
- 测试必须使用标准库 unittest 执行，执行命令为 uv run python -m unittest。

## 关键评审焦点

- 运行目录下未创建 accounts 目录时需自动创建该目录。
- 扫码登录已失效或超时的会话需给出明确提示并重置轮询计时器。
- 手动答题会话超时或用户选择跳过时后端工作线程需正确以空值恢复执行而非永久死锁。
- 全量配置保存时若传入非法数据类型需在校验层拦截并返回明确错误响应。
- 视频倍速滑块快速拖动未松开鼠标时不应向后台工作线程高频发送广播请求。
